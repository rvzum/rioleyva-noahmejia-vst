RIO LEYVA x NOAH MEJIA VST — MIDI Visualizer + Melody Instrument

This installs the RIO LEYVA x NOAH MEJIA VST3 plugin for every user on this Mac, at:

/Library/Audio/Plug-Ins/VST3/RIO LEYVA x NOAH MEJIA VST.vst3

You'll be asked for an administrator password to continue.

After installing: open your DAW (e.g. FL Studio) and rescan plugins if it doesn't appear automatically — in FL Studio: Options → Manage Plugins → Find plugins.
