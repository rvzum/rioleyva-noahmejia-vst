# Установщик RIO LEYVA x NOAH MEJIA VST (.pkg) для macOS

Пакует Release-сборку плагина (universal binary: Intel + Apple Silicon) в
обычный `.pkg`-установщик, который кладёт `RIO LEYVA x NOAH MEJIA VST.vst3` в
`/Library/Audio/Plug-Ins/VST3/` — то есть плагин увидят все пользователи
этого Mac, а не только тот, кто ставил.

## Как собрать установщик

В обычном Terminal.app **на своём Mac** (не через удалённый мост/VM —
`pkgbuild`/`productbuild` существуют только в настоящей macOS):

```bash
cd "~/27wav rioleyva x noahmejia VST"
chmod +x Scripts/build_installer.sh   # один раз
./Scripts/build_installer.sh
```

Результат: `Packaging/build/RIO LEYVA x NOAH MEJIA VST Installer.pkg`.

Скрипт сам:
1. Настраивает и собирает Release-версию плагина в отдельной папке
   `build-release/` (твоя обычная `build/` для разработки не трогается).
2. Собирает только VST3 (без Standalone-приложения — как договорились).
3. Упаковывает `.vst3` через `pkgbuild` + `productbuild` в один `.pkg` с
   приветственным экраном и путём установки
   `/Library/Audio/Plug-Ins/VST3/`.

**Это ещё не проверялось на реальной сборке** — я не могу запускать
`pkgbuild`/`productbuild` сам (мост к твоему Mac работает через Linux-VM,
где этих macOS-инструментов физически нет), поэтому первый прогон нужно
сделать тебе и прислать вывод терминала, если что-то пойдёт не так.

## Важно: установщик НЕ подписан

У тебя нет Apple Developer ID, поэтому `.pkg` не подписан и не
нотарифицирован (не проходил проверку Apple). Это значит: при попытке
открыть его **на любом чужом Mac** сработает Gatekeeper и появится
предупреждение о "неизвестном разработчике". Плагин при этом полностью
рабочий — это просто стандартная защита macOS от неподписанного софта, не
баг.

### Что сказать получателям установщика

Перешли им это (или своими словами):

> При открытии `RIO LEYVA x NOAH MEJIA VST Installer.pkg` macOS покажет предупреждение
> "нельзя открыть, т.к. он от неустановленного разработчика". Это нормально
> для установщика без платной Apple-подписи ($99/год). Чтобы всё равно
> установить:
>
> 1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
> 2. Прокрутите вниз до раздела "Безопасность" — там будет строка про
>    заблокированный `RIO LEYVA x NOAH MEJIA VST Installer.pkg` и кнопка **"Открыть все
>    равно"** ("Open Anyway"). Нажмите её, введите пароль/Touch ID.
> 3. Запустите установщик ещё раз — теперь появится обычное окно с
>    подтверждением, нажмите **"Открыть"**.
>
> (Альтернативный способ: правый клик / Control+клик по файлу `.pkg` →
> "Открыть" — на части версий macOS сработает сразу, без похода в
> настройки.)
>
> Если DAW при первом сканировании плагина тоже покажет похожее
> предупреждение — тот же путь через Системные настройки решает и это.

### Если захочешь убрать это предупреждение совсем

Единственный способ — Apple Developer Program ($99/год): получить
Developer ID Application + Installer сертификаты, подписать `.vst3` и
`.pkg` (`codesign`), и прогнать через нотарификацию Apple (`notarytool`).
После этого установщик будет открываться без единого предупреждения у
любого получателя. Могу подготовить обновлённый скрипт под это, когда
будет аккаунт — просто скажи.

## Структура

```
Scripts/build_installer.sh   -- сборка + упаковка (см. выше)
Packaging/
  Distribution.xml           -- описание установщика для productbuild
                                 (плейсхолдеры __VERSION__ и т.п.
                                 подставляются скриптом при каждой сборке)
  Resources/
    Welcome.html              -- текст на первом экране установщика
    Conclusion.html           -- текст на экране "готово"
  build/                      -- сюда попадает итоговый .pkg (не в git)
```

## Версия

Версия установщика берётся из `project(27wavVST VERSION 0.1.0 ...)` в
корневом `CMakeLists.txt` — подними её там перед следующим релизом, скрипт
подхватит автоматически.
