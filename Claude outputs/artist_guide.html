Установка — 5 шагов
Шаг 1
Скачай файл
Перейди по ссылке выше и сохрани 27wav rioleyva VST Installer.pkg — он появится в папке «Загрузки».
Шаг 2
Открой файл — Mac предупредит, это нормально
Дважды кликни по установщику. macOS покажет: «нельзя открыть — от неизвестного разработчика». Это стандартная защита, у плагина просто нет платной подписи Apple.
Нажми «Готово» / закрой окно — не нажимай «В корзину». Переходи к шагу 3.
Шаг 3
Разреши установку в настройках
Открой Системные настройки → Конфиденциальность и безопасность, прокрути вниз до раздела «Безопасность». Там будет строка про заблокированный установщик и кнопка Открыть все равно — нажми её и подтверди паролем или Touch ID.
Шаг 4
Пройди установку
Снова открой 27wav rioleyva VST Installer.pkg — теперь появится обычное окно установщика. Жми Продолжить → Установить, введи пароль от Mac. Плагин ляжет в системную папку плагинов — сразу для всех, кто пользуется этим Mac.
Шаг 5
Найди плагин в FL Studio
Открой (или перезапусти) FL Studio → Options → Manage Plugins → Find plugins. Затем в Channel Rack → + → Select generator plugin найди по имени «27wav» и добавь — плагин появится как обычный инструмент.
Плагин только показывает MIDI — звук через него не проходит, добавляй его рядом с обычным инструментом на канале.
