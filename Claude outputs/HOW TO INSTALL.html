Installation — 5 steps
Step 1
Download the file
Use the link above and save 27wav rioleyva VST Installer.pkg — it'll land in your Downloads folder.
Step 2
Open it — macOS will warn you, that's expected
Double-click the installer. macOS will say it "can't be opened because it is from an unidentified developer." That's just standard protection — this plugin doesn't have a paid Apple signature.
Click "Done" / close the dialog — don't move it to the Trash. Continue to step 3.
Step 3
Allow it in System Settings
Open System Settings → Privacy & Security, scroll down to the "Security" section. You'll see a line about the blocked installer with an Open Anyway button — click it and confirm with your password or Touch ID.
Step 4
Run the installer
Open 27wav rioleyva VST Installer.pkg again — this time the normal installer window shows up. Click Continue → Install, enter your Mac password. The plugin goes into the system plugins folder — available to everyone who uses this Mac.
Step 5
Find it in FL Studio
Open (or restart) FL Studio → Options → Manage Plugins → Find plugins. Then in Channel Rack → + → Select generator plugin, search for "27wav" and add it — it shows up like a regular instrument.
The plugin only visualizes MIDI — no audio passes through it, so add it alongside a regular instrument on the channel.
